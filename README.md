# 路面裂缝两层卷积 · 边缘部署演示（分块选型 + 整数量化对照）

FastAPI + NumPy（浮点全程 float64）实现的网页小工具，包含两个页面：

1. **分块尺寸选型**（`/`）：上传一张每边至多 512 像素的灰度 PNG 和两层卷积的
   权重/偏置 JSON，在给定的第一层输入激活预算下，从 1～64 中选出预算允许的最大
   **方形输出分块边长**，并分别用分块推理和独立整图基准跑分，报告峰值用量、
   最大绝对误差及其坐标，误差 > 1e-8 判失败。
2. **量化对照**（`/quant`）：上传每边至多 128 像素的灰度 PNG 与原权重 JSON，
   填写三个正量化尺度，并排展示整数量化推理与整图浮点推理在裂缝判定上的差异
   （新增/消失的输出网格像素）。

## 网络结构（固定）

| 层 | 通道 | 核 | 步长 | 膨胀 | 零填充 | 激活 |
|---|---|---|---|---|---|---|
| layer1 | 1 → 4 | 3×3 | 2 | 1 | 1 | ReLU |
| layer2 | 4 → 1 | 3×3 | 1 | 2 | 2 | — |

## 预算口径与选型规则

- 对每个输出分块（边缘块按实际输出尺寸**裁短**），沿两层感受野链路反推出
  覆盖它所需的**图内激活最小矩形窗口**，元素数 = 窗口高 × 窗口宽 × 输入通道数；
  图外零填充不物化、不计入。
- 窗口公式（layer2 dilation 2 使单输出在 layer1 输出上跨度 `[i−2, i+2]`，
  layer1 stride 2 再映射到输入）：
  行窗口 `[2·r0−5, 2·(r1−1)+6)`，列窗口同理，最后裁到图界。
- 边长 `s` 的峰值 = 该 s 下所有分块窗口元素数的最大值（内部块通常最大，
  边缘块被图界裁短）。从 1～64 中选峰值 ≤ 预算的最大 s。
- 实跑时分块路径截取的正是同一窗口；流水线对“实跑峰值 == 规划峰值且
  ≤ 预算”做硬性断言，守住预算。
- 当单像素块（s=1）仍超预算时，**不执行推理**，只返回最低所需预算。

## 运行方式

### Docker Compose（推荐）

```bash
docker compose up --build
# 浏览器打开 http://localhost:8000
```

### 本地 Python（3.11+）

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### 权重 JSON 格式

```json
{
  "layer1": {"weight": [[[[...3x3...]]]], "bias": [0, 0, 0, 0]},
  "layer2": {"weight": [...形状 1x4x3x3...], "bias": [0]}
}
```
形状要求：layer1.weight `(4,1,3,3)`、layer1.bias `(4,)`、
layer2.weight `(1,4,3,3)`、layer2.bias `(1,)`。

### 样例

`scripts/make_samples.py` 生成确定性样例（已随仓库提供于 `samples/`）：

```bash
python3 -I scripts/make_samples.py samples
# sample_crack_64.png（64×64 裂缝灰度图）
# sample_random_8.png（8×8 随机图，便于手工核对窗口）
# weights.json（两层权重与偏置）
# weights_quant_demo.json（零均值权重，量化对照页默认尺度即可见新增/消失差异）
```

页面上传两个文件并填入预算（元素数）即可；勾选“以 JSON 返回”便于脚本调用。

## 量化对照页（/quant）

### 量化口径（固定）

| 量 | 口径 |
|---|---|
| 首层输入 | 灰度字节 uint8，输入尺度固定 `s_x = 1/255` |
| 权重 | `q_w = clip(round_half_even(w / s_w), -128, 127)`，饱和到 int8 |
| 舍入 | 最近整数，遇半取偶（banker's rounding） |
| 偏置 | 尺度 = 该层输入尺度 × 该层权重尺度；按同口径舍入，硬性要求落在 int32 |
| 首层 ReLU | 整数累加器过 int32 检查后做 ReLU，按 `s_a1` 重定标并饱和到 uint8 |
| 次层输入 | 直接读取首层重定标后的 uint8 字节 |
| 次层输出 | int8 权重 × uint8 激活的带偏置点积，int64 累加并硬性检查 int32 |

两层卷积沿用与浮点路完全相同的 stride / dilation / zero-padding（layer1
stride 2、pad 1；layer2 stride 1、dilation 2、pad 2）。页面需要填写三个**正**
尺度：`s_w1`（layer1 权重）、`s_w2`（layer2 权重）、`s_a1`（首层 ReLU 输出，
即次层输入尺度）；偏置尺度 `s_x·s_w1` 与 `s_a1·s_w2` 由页面派生并展示。

### 判定与对照

- 浮点路：对原始权重与归一化图像做整图 float64 推理（复用选型页同一基准实现），
  分数 ≥ 0 判裂缝；
- 整数路：次层带偏置整数累加器即分数，累加器 ≥ 0 判裂缝；
- 在输出网格上分别标记**量化新增**（整数判裂缝、浮点未判，红）与**量化消失**
  （浮点判裂缝、整数未判，蓝），四联图另含原图与两路各自的二值判定；
- JSON 响应含全量掩码与坐标、各尺度、权重饱和计数与前后 8 个分数样例。

### 硬性失败（只显示原因，清掉旧图）

任一情况都中止计算，结果区只渲染错误原因、不保留任何上一次的图像：

- 量化偏置超出 int32；
- layer1 / layer2 的带偏置点积累加器超出 int32；
- 任何中间结果出现 NaN/Inf 等非有限值；
- 尺度非正或非有限、图像/JSON 不合规。
